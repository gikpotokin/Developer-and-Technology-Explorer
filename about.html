About DTX

One place to explore the developer ecosystem.

Developer & Technology Explorer combines public GitHub developer and repository data with technology articles from Dev.to.

The project demonstrates asynchronous JavaScript, REST APIs, dynamic rendering, responsive design, accessibility, error handling, ES modules, and browser storage.

Technology stack

  • HTML5 + CSS3
  • Vanilla JavaScript + ES Modules
  • GitHub REST API
  • Dev.to API
  • localStorage
